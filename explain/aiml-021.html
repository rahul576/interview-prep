How does a neural network work at a basic level, and what are activation functions for?

AI/ML & GenAI · concept · levels entry, mid

In one line

A neural network stacks layers of neurons that each compute a weighted sum plus bias followed by an activation function; activations add non-linearity, without which the whole network would collapse to a single linear model.

Detailed explanation

Each neuron receives inputs x, multiplies them by weights w, adds a bias b and applies an activation: output = f(w·x + b). A layer is many neurons in parallel, implemented as a matrix multiplication. Data flows from the input layer through hidden layers to the output layer; this is the forward pass. The weights start random and are learned.

Activation functions are what make deep learning powerful. A composition of linear functions is still linear, so without non-linear activations a 50-layer network could only draw straight decision boundaries. With them, networks are universal approximators able to represent very complex functions. Common choices: ReLU (max(0, x)), cheap and avoids vanishing gradients for positive inputs, the default for many hidden layers; Leaky ReLU avoids "dead" neurons; GELU and SiLU/SwiGLU variants, smooth functions used in transformers; sigmoid, mapping to (0, 1) for binary outputs; tanh, mapping to (-1, 1); and softmax in the output layer to turn scores (logits) into a probability distribution over classes.

Training compares outputs with targets using a loss function (cross-entropy, MSE), computes gradients with backpropagation, and updates weights using gradient descent variants like Adam. Deep networks learn hierarchical representations: in images, early layers detect edges, middle layers textures and shapes, later layers object parts; in language, layers move from token patterns to syntax to meaning. Regularisation such as dropout, weight decay and normalisation layers keeps them stable and generalising.

How it works

  1. Input features enter the first layer.
  2. Each layer computes weighted sums plus biases (a matrix multiply).
  3. An activation function is applied element-wise.
  4. The output layer produces logits, turned into probabilities by softmax or sigmoid.
  5. The loss is computed, gradients flow back, and weights are updated; repeat for many batches.

Example

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(20, 64), nn.ReLU(),
    nn.Linear(64, 32), nn.ReLU(),
    nn.Linear(32, 3)            # logits for 3 classes
)
loss_fn = nn.CrossEntropyLoss()  # applies log-softmax internally

Common mistakes

  • Saying activations "normalise" outputs rather than adding non-linearity.
  • Applying softmax before a loss that already includes it, like PyTorch CrossEntropyLoss.
  • Using sigmoid in deep hidden layers and hitting vanishing gradients.
  • Thinking more layers always means better results without enough data.

How to answer in the interview

"A neural network is layers of neurons; each neuron takes a weighted sum of its inputs plus a bias and passes it through an activation function, and each layer feeds the next. Activations add non-linearity; without them, stacking layers is still just one linear function. I'd use ReLU or GELU in hidden layers, sigmoid for a binary output and softmax for multi-class. Training uses a loss, backpropagation and gradient descent to adjust weights, and deep networks learn hierarchical features, like edges to shapes to objects."

Likely follow-up questions

  • Why did ReLU replace sigmoid in hidden layers? Sigmoid saturates and shrinks gradients; ReLU keeps gradient 1 for positive inputs and is cheap.
  • What is a dead ReLU? A neuron stuck outputting zero for all inputs; Leaky ReLU or careful initialisation helps.
  • What does dropout do? Randomly zeroes activations during training to reduce overfitting.
