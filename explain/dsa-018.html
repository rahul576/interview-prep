How do you find the lowest common ancestor of two nodes in a binary tree?

DSA: Trees & Graphs · concept · levels mid

In one line

For a general binary tree, recurse. Return the node if it is null or one of the targets. If both subtrees return non-null, the current node is the LCA. Otherwise bubble up the non-null side. That is O(n) time, O(h) space. In a BST, use the values: go left if both are smaller, right if both are larger, else you've found it (O(h)).

Detailed explanation

The lowest common ancestor of p and q is the deepest node that has both as descendants. A node counts as its own descendant, so if p is an ancestor of q, the LCA is p.

General binary tree (no ordering). Each recursive call answers: "does this subtree contain p or q, and if it contains both, what is their LCA?"

  • null returns null.
  • If node == p or node == q, return node. There is no need to look deeper. If the other target is below, this node is the LCA. If it is elsewhere, an ancestor will see both sides.
  • Otherwise recurse left and right.
  • Both non-null: p and q are in different subtrees, so this node is the split point, the LCA.
  • One non-null: pass it up. It is either a found target or an LCA already found deeper.

Each node is visited at most once, so it is O(n) time with O(h) recursion. This assumes both nodes exist in the tree. If they might not, count how many targets were actually found and only return the result if both were.

BST shortcut. Ordering tells us where both nodes are. Starting at the root: if both values are smaller, the LCA is in the left subtree. If both are larger, it is in the right. Otherwise they split here (or one equals the node), so this is the LCA. It is iterative, O(h) time, O(1) space.

With parent pointers: treat it like the intersection of two linked lists. Walk up from p storing ancestors in a set, then walk up from q until you hit one. Or use the two-pointer trick of switching to the other node when you reach the root, which is O(h) and O(1) space.

How it works

  1. lca(node): if node == null || node == p || node == q, return node.
  2. L = lca(node.left), R = lca(node.right).
  3. If L != null && R != null, return node.
  4. Return L != null ? L : R.

Example

public TreeNode lca(TreeNode node, TreeNode p, TreeNode q) {
    if (node == null || node == p || node == q) return node;
    TreeNode left = lca(node.left, p, q);
    TreeNode right = lca(node.right, p, q);
    if (left != null && right != null) return node;
    return left != null ? left : right;
}

public TreeNode lcaBst(TreeNode root, TreeNode p, TreeNode q) {
    TreeNode n = root;
    while (n != null) {
        if (p.val < n.val && q.val < n.val) n = n.left;
        else if (p.val > n.val && q.val > n.val) n = n.right;
        else return n;
    }
    return null;
}
//        3
//      5   1        LCA(6, 4) = 5 ; LCA(5, 1) = 3 ; LCA(5, 4) = 5
//     6 2
//      7 4

Common mistakes

  • Searching for paths into lists every time when a single traversal suffices (that still works, but costs more memory and code).
  • Not handling the case where one node is the ancestor of the other.
  • Assuming both nodes exist without clarifying.
  • Using the BST shortcut on a non-BST.

How to answer in the interview

"For a general binary tree I recurse. If the current node is null or equals either target, I return it. Otherwise I search the left and right subtrees. If both sides return non-null, the targets are split across this node, so it's the lowest common ancestor. If only one side is non-null, I pass that up. It's O(n) time and O(h) stack space, and it handles one node being the ancestor of the other. In a BST I'd use the values: if both are smaller go left, if both are larger go right, otherwise the current node is the answer, which is O(h)."

Likely follow-up questions

  • Nodes with parent pointers? Like the intersection of two linked lists: an ancestor set, or two pointers that switch starts.
  • Many LCA queries on a static tree? Binary lifting (O(log n) per query) or Euler tour plus RMQ.
  • What if a node may not exist? Track found flags and verify both were seen.
