How would you solve the longest common subsequence problem?

DSA: Algorithms & DP · concept · levels mid, senior

In one line

Build a 2D table over prefixes: dp[i][j] = the LCS length of a[0..i) and b[0..j). If the characters match, take diagonal + 1. Otherwise take the max of top and left. The answer is dp[m][n]. That is O(m·n) time, and space can be reduced to two rows (O(min(m, n))). Backtrack to recover the sequence. It underlies diff tools.

Detailed explanation

A subsequence keeps the order but not necessarily contiguity. "ACE" is a subsequence of "ABCDE". The longest common subsequence of "ABCBDAB" and "BDCABA" has length 4 (for example "BCBA"). Brute force over all 2^m subsequences is hopeless, but the problem has optimal substructure over prefixes:

  • If the last characters match (a[i-1] == b[j-1]), that character can end an LCS: dp[i][j] = dp[i-1][j-1] + 1.
  • If they don't match, at least one of them is not in the LCS, so drop one: dp[i][j] = max(dp[i-1][j], dp[i][j-1]).
  • Base: an empty prefix gives LCS 0, so row 0 and column 0 are zeros. A table of size (m+1) × (n+1) avoids index checks.

Recovering the subsequence: start at dp[m][n]. If the characters match, include that character and move diagonally. Otherwise move toward the larger neighbour (up or left). Reverse the collected characters at the end.

Space optimisation: each row depends only on the previous row, so keep two rows (or one row plus a saved diagonal variable), which is O(min(m, n)). That only gives the length. Recovering the actual sequence in linear space needs Hirschberg's algorithm.

Real-world: diff, git diff and code review tools compute a minimal edit script related to LCS. Git uses the Myers diff algorithm, which is O((m+n)·D) where D is the number of differences. It is also used in DNA sequence alignment and plagiarism detection.

LCS vs edit distance: LCS allows only insertions and deletions, implicitly. Edit distance (Levenshtein) also allows substitutions and minimises operations: dp[i][j] = dp[i-1][j-1] if the characters match, else 1 + min(insert, delete, replace). With only inserts and deletes allowed, distance = m + n - 2·LCS.

How it works

  1. Create dp[m+1][n+1], all zeros.
  2. For i in 1..m, j in 1..n:
  3. Match: dp[i][j] = dp[i-1][j-1] + 1.
  4. Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1]).
  5. Return dp[m][n], and backtrack for the string.

Example

String lcs(String a, String b) {
    int m = a.length(), n = b.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                ? dp[i - 1][j - 1] + 1
                : Math.max(dp[i - 1][j], dp[i][j - 1]);

    StringBuilder sb = new StringBuilder();
    for (int i = m, j = n; i > 0 && j > 0; ) {
        if (a.charAt(i - 1) == b.charAt(j - 1)) { sb.append(a.charAt(i - 1)); i--; j--; }
        else if (dp[i - 1][j] >= dp[i][j - 1]) i--;
        else j--;
    }
    return sb.reverse().toString();
}
// lcs("ABCDE", "ACE") -> "ACE" (length 3)

Common mistakes

  • Confusing subsequence with substring. The longest common substring resets to 0 on a mismatch.
  • Off-by-one errors from not using the extra row and column.
  • Optimising to two rows and then trying to backtrack.
  • Claiming git uses plain LCS DP (it uses Myers' algorithm, which is related).

How to answer in the interview

"I'd build a 2D table where dp[i][j] is the LCS length of the first i characters of one string and the first j of the other. If the characters at i and j match, it's the diagonal value plus one. Otherwise it's the max of the cell above and the cell to the left, since one of the characters must be dropped. Row and column zero are zeros for empty prefixes, and the answer is the bottom-right cell. That's O(m times n) time and space, and the space can drop to two rows if I only need the length. Backtracking through the table recovers the subsequence. This is the foundation of diff tools."

Likely follow-up questions

  • Edit distance versus LCS? Edit distance adds substitutions and minimises operations. LCS maximises matches.
  • Longest common substring? On a mismatch dp = 0, and track the max anywhere.
  • Very long strings? Use two-row space, Hirschberg for reconstruction, or Myers' algorithm when the inputs are similar.
