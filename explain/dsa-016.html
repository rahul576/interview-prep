What are the tree traversal orders, and how do you do a level-order traversal?

DSA: Trees & Graphs · concept · levels entry

In one line

Depth-first orders are preorder (node, left, right), inorder (left, node, right, which is sorted for a BST) and postorder (left, right, node). Level order is breadth-first using a queue, processing queue.size() nodes per level. All are O(n) time. DFS uses O(height) space, BFS uses O(width).

Detailed explanation

A traversal visits every node exactly once. The order determines what problems it solves.

DFS orders (naturally recursive, or with an explicit stack):

  • Preorder (root first): copying or serialising a tree, printing directory structures, prefix expressions.
  • Inorder: for a binary search tree it visits keys in sorted order. Used for validating a BST and finding the kth smallest.
  • Postorder (children first): anything where the parent depends on its children, such as computing subtree sizes or heights, deleting or freeing a tree, and evaluating expression trees.

Level order (BFS) visits nodes level by level using a FIFO queue. The trick for grouping by level is to snapshot the queue size at the start of each level and poll exactly that many nodes, enqueueing their children for the next level. Uses: printing levels, minimum depth (stop at the first leaf), right side view (the last node of each level), zigzag traversal, and connecting next pointers.

Space. Recursive DFS uses the call stack, O(h), where h is the height: O(log n) if balanced, O(n) if skewed. On very deep trees, recursion can overflow in Java, so use an iterative stack. BFS holds up to a full level, O(w), which can be about n/2 at the bottom of a complete tree. Morris traversal does inorder in O(1) space by temporarily threading the tree.

How it works

  1. If root is null, return empty.
  2. queue.offer(root).
  3. While the queue is not empty: size = queue.size(), create a level list.
  4. Repeat size times: node = poll(), add its value, offer the non-null left and right children.
  5. Add level to the result.

Example

// Inorder (recursive)
void inorder(TreeNode n, List<Integer> out) {
    if (n == null) return;
    inorder(n.left, out); out.add(n.val); inorder(n.right, out);
}

// Level order (BFS)
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> q = new ArrayDeque<>(List.of(root));
    while (!q.isEmpty()) {
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            level.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        res.add(level);
    }
    return res;
}
//      4
//    2   6      pre: 4 2 1 3 6   in: 1 2 3 4 6   post: 1 3 2 6 4
//   1 3         level: [[4],[2,6],[1,3]]

Common mistakes

  • Not snapshotting queue.size(), which mixes levels.
  • Using a stack for BFS (that gives DFS).
  • Claiming DFS is O(log n) space for all trees (only balanced ones).
  • Forgetting that inorder is sorted only for BSTs.

How to answer in the interview

"There are three depth-first orders. Preorder visits the node, then left, then right, which is good for copying or serialising. Inorder is left, node, right, which gives sorted order for a BST. Postorder visits the children before the node, which is useful for sizes, heights or deleting a tree. Level order is breadth-first: I put the root in a queue, and while it's not empty I record its size, poll that many nodes as one level, and enqueue their children. Every traversal is O(n) time. DFS uses O(height) space and BFS O(width)."

Likely follow-up questions

  • Right side view? BFS, taking the last node of each level. Or DFS visiting right first and recording the first node at each depth.
  • Iterative inorder? Push left nodes onto a stack, pop and visit, then go right.
  • Zigzag order? BFS, reversing every other level (or adding to the front of a deque).
