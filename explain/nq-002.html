What major features were introduced after Java 8, particularly in Java 11, Java 17, and Java 21?

Modern Java (11-21) · concept · levels mid, senior

In one line

After Java 8 Java moved to a six-month release cadence with LTS releases 11, 17, 21 (and 25): 11 brought var, HttpClient, new String methods; 17 made records, sealed classes, text blocks, switch expressions and instanceof patterns standard; 21 added virtual threads, pattern matching for switch, record patterns and sequenced collections.

Detailed explanation

Java 9-11. Java 9 introduced the module system (JPMS), JShell and collection factory methods such as List.of and Map.of. Java 10 added var for local variable type inference. Java 11 (LTS) standardised the java.net.http.HttpClient with HTTP/2 and async support, added String methods isBlank, strip, lines, repeat, var in lambda parameters, Files.readString, and single-file source launch (java Hello.java). It also removed Java EE modules (JAXB, JAX-WS) and introduced the experimental ZGC and Flight Recorder in OpenJDK.

Java 12-17. Switch expressions (14), helpful NullPointerException messages (14), text blocks (15), records and pattern matching for instanceof (16), and sealed classes (17). Java 17 (LTS) also introduced the new RandomGenerator API and strongly encapsulated JDK internals. ZGC became production-ready in 15.

Java 18-21. UTF-8 became the default charset (18) and a simple web server tool arrived. Java 21 (LTS) finalised virtual threads, pattern matching for switch, record patterns and sequenced collections, and added generational ZGC. Structured concurrency and scoped values were previews.

After 21. Java 22 finalised the Foreign Function and Memory API and unnamed variables (_); Java 24 removed most virtual-thread pinning on synchronized; Java 25 (LTS, September 2025) finalised scoped values, module import declarations, compact source files and flexible constructor bodies.

How it works

  1. Feature releases every March and September.
  2. Big features go through incubator and preview stages first.
  3. Every fourth release (two years) is LTS with long vendor support.
  4. Teams adopt LTS versions in production and test previews in side projects.

var client = HttpClient.newHttpClient();
String body = client.send(HttpRequest.newBuilder(URI.create(url)).build(),
        HttpResponse.BodyHandlers.ofString()).body();

// Java 17
record Money(BigDecimal amount, String currency) {}
String sql = """
    SELECT * FROM orders WHERE status = ?
    """;

// Java 21
String describe(Shape s) {
    return switch (s) {
        case Circle c -> "circle r=" + c.r();
        case Square(double side) -> "square " + side;
    };
}

Common mistakes

  • Saying records or virtual threads came in Java 11.
  • Confusing preview features with final ones.
  • Forgetting that Java 11 removed Java EE modules, which breaks old code.
  • Ignoring non-language improvements such as GC and NPE messages.

How to answer in the interview

"Since Java 9 there's a release every six months, with LTS versions 11, 17, 21 and now 25. Java 9 to 11 gave us modules, collection factories like List.of, var, the standard HttpClient and String helpers like isBlank, strip and lines. By 17 we had records, sealed classes, text blocks, switch expressions and instanceof pattern matching, plus helpful NPE messages. Java 21 brought virtual threads, pattern matching for switch, record patterns and sequenced collections, and generational ZGC. Java 25 then finalised scoped values. The biggest practical impact for me has been records and virtual threads."

Likely follow-up questions

  • Which of these features has had the most impact on your code? Records for DTOs and pattern matching over sealed types; virtual threads for I/O-bound services.
  • What is a preview feature? A complete but not final feature enabled with --enable-preview, which may change.
  • What did Java 11 remove? Java EE and CORBA modules such as JAXB and JAX-WS.
