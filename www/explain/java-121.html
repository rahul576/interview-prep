What is the difference between map and flatMap in streams, and how does Collectors.groupingBy work?

Java 8+ Features · concept · levels entry, mid

In one line

map transforms each element one-to-one, flatMap maps each element to a stream and flattens the results into one stream, and Collectors.groupingBy builds a Map keyed by a classifier function, optionally with a downstream collector such as counting() or mapping().

Detailed explanation

map(Function<T,R>) produces exactly one output per input. A Stream<Order> mapped with Order::total becomes a Stream<BigDecimal>. If the function itself returns a collection or stream, map gives you a nested structure, such as Stream<List<Item>>, which is rarely what you want.

flatMap(Function<T, Stream<R>>) solves this: each element becomes zero or more elements, and all the inner streams are concatenated into a single Stream<R>. orders.stream().flatMap(o -> o.items().stream()) yields every item across all orders. Java 16 added mapMulti, an imperative alternative that can avoid creating small inner streams. Primitive variants like flatMapToInt exist too.

Collectors.groupingBy(classifier) applies the classifier to each element and collects elements with the same key into a Map<K, List<T>> (a HashMap by default). The real power is the downstream collector: groupingBy(Order::customerId, counting()) gives a count per customer; summingInt, averagingDouble, mapping(f, toSet()), maxBy(comparator) and reducing are common. A three-argument overload accepts a map factory, for example TreeMap::new for sorted keys. partitioningBy(predicate) is the special case with a boolean key and always contains both true and false entries. For parallel streams there is groupingByConcurrent.

How it works

  1. map calls the function per element and emits the result.
  2. flatMap calls the function, receives a stream, and pushes each of its elements downstream.
  3. groupingBy computes a key per element and looks up or creates that key's container.
  4. The downstream collector accumulates each element into its group.
  5. A finisher produces the final map values (e.g. counts as Long).

Example

record Item(String sku, int qty) {}
record Order(String customer, BigDecimal total, List<Item> items) {}

List<BigDecimal> totals = orders.stream().map(Order::total).toList();

List<Item> allItems = orders.stream()
    .flatMap(o -> o.items().stream())
    .toList();

Map<String, Long> ordersPerCustomer = orders.stream()
    .collect(Collectors.groupingBy(Order::customer, Collectors.counting()));

Map<String, Set<String>> skusPerCustomer = orders.stream()
    .collect(Collectors.groupingBy(Order::customer, TreeMap::new,
        Collectors.flatMapping(o -> o.items().stream().map(Item::sku), Collectors.toSet())));

// Top three customers by total value
List<String> top3 = orders.stream()
    .collect(Collectors.groupingBy(Order::customer,
        Collectors.reducing(BigDecimal.ZERO, Order::total, BigDecimal::add)))
    .entrySet().stream()
    .sorted(Map.Entry.<String, BigDecimal>comparingByValue().reversed())
    .limit(3).map(Map.Entry::getKey).toList();

Common mistakes

  • Using map and ending with Stream<List<T>> instead of flatMap.
  • Grouping into lists and then post-processing instead of using a downstream collector.
  • Assuming groupingBy returns a sorted or ordered map.
  • Forgetting the classifier must not return null (it throws NPE).

How to answer in the interview

"map is a one-to-one transformation: orders become totals. flatMap maps each element to a stream and flattens them, so orders that each contain a list of items become a single stream of items. groupingBy takes a classifier and builds a map from key to a list by default, but I almost always pass a downstream collector, like counting to count orders per customer, or mapping or summing. I can also pass a map factory such as TreeMap. partitioningBy is the boolean-key special case."

Likely follow-up questions

  • How would you find the top three customers by total order value? Group with a summing/reducing downstream, then sort entries by value descending and limit 3.
  • What does flatMapping do? Java 9 downstream collector that flattens inside a group.
  • What does partitioningBy return if nothing matches? A map with both keys, one list empty.
