What is the difference between classification and regression problems?

AI/ML & GenAI · concept · levels entry, mid

In one line

Classification predicts a category (binary, multi-class or multi-label), evaluated with accuracy, precision, recall, F1, ROC-AUC; regression predicts a continuous number, evaluated with MAE, RMSE, R-squared.

Detailed explanation

The type of target determines the problem type, and with it the algorithms, loss functions and metrics.

Classification assigns an input to one or more categories. Binary classification has two classes: fraud or not, churn or not. Multi-class has several mutually exclusive classes: route a ticket to billing, technical or sales. Multi-label allows several labels at once: tag an article as both "cloud" and "security". Models typically output probabilities, and a threshold turns them into decisions; choosing it trades precision against recall. Loss functions include cross-entropy (log loss). Metrics: accuracy (misleading on imbalanced data), precision (of predicted positives, how many are right), recall (of actual positives, how many were found), F1, ROC-AUC and PR-AUC for imbalanced problems.

Regression predicts a continuous numeric value: house price, delivery time, next month's demand, server load. Loss functions include mean squared error and mean absolute error; metrics are MAE (average absolute error, in the target's units), RMSE (penalises large errors more), MAPE and R-squared (share of variance explained).

Many algorithms come in both forms (decision trees, gradient boosting, neural networks). Logistic regression, despite its name, is a classification algorithm. Some problems can be framed either way: a customer rating can be predicted as a number or as one of five classes; delivery delay as minutes (regression) or "late / on time" (classification). The right framing depends on how the prediction will be used.

How it works

  1. Look at the target: category or number?
  2. Choose framing according to the business decision.
  3. Pick algorithm and loss function accordingly.
  4. Evaluate with matching metrics on held-out data.
  5. For classification, tune the decision threshold to business costs.

Example

from sklearn.ensemble import GradientBoostingClassifier, GradientBoostingRegressor
from sklearn.metrics import precision_score, recall_score, mean_absolute_error

clf = GradientBoostingClassifier().fit(X_train, y_is_late)         # classification
p_late = clf.predict_proba(X_test)[:, 1]
pred = p_late > 0.3                                                 # threshold chosen for recall
print(precision_score(y_test_late, pred), recall_score(y_test_late, pred))

reg = GradientBoostingRegressor().fit(X_train, y_delay_minutes)     # regression
print(mean_absolute_error(y_test_minutes, reg.predict(X_test)))

Common mistakes

  • Reporting accuracy on heavily imbalanced data.
  • Thinking logistic regression is a regression model.
  • Using the default 0.5 threshold without considering costs.
  • Treating ordered categories as plain numbers without thinking.

How to answer in the interview

"Classification predicts a category: binary like fraud or not, multi-class like routing a ticket to one team, or multi-label where several tags apply. Models usually output probabilities and a threshold makes the decision. Regression predicts a continuous number, like a price or delivery time. That choice drives loss functions and metrics: precision, recall, F1 and AUC for classification, MAE and RMSE for regression. Some problems can be framed either way, so I choose based on how the prediction will be used."

Likely follow-up questions

  • Delivery delay framing? Regression for ETAs; classification if the decision is "warn customer or not".
  • Imbalanced classes? Use PR-AUC, recall at precision, class weights or resampling.
  • MAE vs RMSE? RMSE punishes big errors more.
