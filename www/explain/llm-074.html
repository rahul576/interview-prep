Explain at a high level how transformer models and attention work.

LLMOps & RAG · concept · levels entry, mid

In one line

A transformer turns tokens into embeddings with positional information, then uses self-attention, where each token's query is compared with every token's key to weight their values, across multiple heads and stacked layers of attention and feed-forward networks; modern LLMs are mostly decoder-only models predicting the next token, and parallel training made scaling possible.

Detailed explanation

Embeddings and position. Each input token ID is mapped to a learned vector (the token embedding). Because attention itself has no notion of order, positional information is added; modern LLMs commonly use rotary position embeddings (RoPE), which encode relative positions inside the attention computation.

Self-attention. For each token, the model computes three vectors through learned projections: a query (what am I looking for?), a key (what do I contain?) and a value (what do I pass on?). The attention score between token i and token j is the dot product of i's query with j's key, scaled by the square root of the dimension and normalised with softmax. Token i's new representation is the weighted sum of all values. This lets "it" in "the server crashed because it ran out of memory" attend strongly to "server".

Multi-head attention. Several attention heads run in parallel with different projections, capturing different relationships (syntax, coreference, long-range dependencies), and their outputs are concatenated.

Layers. A transformer block combines attention with a position-wise feed-forward network, plus residual connections and normalisation. Dozens of blocks are stacked; representations become more abstract with depth.

Decoder-only LLMs. GPT-style models use causal masking: each token attends only to earlier tokens. They are trained to predict the next token; at inference they generate one token at a time, reusing a KV cache of previous keys and values.

Why it won. Recurrent networks processed tokens sequentially, limiting parallelism. Transformers process all positions of a training sequence in parallel on GPUs, which enabled training on huge datasets and scaling to billions of parameters. The trade-off: attention compares every token with every other, so compute grows quadratically with sequence length.

How it works

  1. Tokenise; look up embeddings; apply positional encoding.
  2. Per layer: compute Q, K, V; attention scores with causal mask; softmax; weighted sum of V.
  3. Concatenate heads; feed-forward; residual and normalisation.
  4. Repeat for all layers.
  5. Final layer -> probabilities over vocabulary -> sample next token.
  6. Append token; repeat using the KV cache.

Example

import numpy as np

def attention(Q, K, V, causal=True):
    d = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d)                  # (n, n) similarity of queries and keys
    if causal:
        scores += np.triu(np.full(scores.shape, -1e9), k=1)  # no peeking at future tokens
    weights = np.exp(scores - scores.max(-1, keepdims=True))
    weights /= weights.sum(-1, keepdims=True)      # softmax per row
    return weights @ V                             # weighted mix of values

Common mistakes

  • Saying the model "understands words"; it processes token vectors.
  • Confusing embeddings (input vectors) with attention.
  • Forgetting that decoder-only models are causal.
  • Ignoring the quadratic cost of attention for long contexts.

How to answer in the interview

"A transformer first turns tokens into embedding vectors and adds positional information so it knows the order. The core is self-attention: each token has a query, key and value; comparing a token's query with all keys gives scores, and its new representation is a weighted mix of the values, so each word takes its context into account. Multiple heads capture different relationships, and many layers of attention plus feed-forward networks build richer representations. Modern LLMs are decoder-only models trained to predict the next token. Unlike RNNs, transformers process a whole sequence in parallel during training, which made scaling possible."

Likely follow-up questions

  • Why quadratic? Every token attends to every other: n x n scores per layer and head.
  • What is the KV cache? Stored keys and values of past tokens, so generation doesn't recompute them.
  • Encoder vs decoder models? Encoders (BERT) see both directions, good for embeddings and classification; decoders generate.
