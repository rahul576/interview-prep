What operational concerns are specific to multimodal LLM features with images, audio or video?

LLMOps & RAG · concept · levels mid, senior

In one line

Multimodal features bring large payloads that raise latency and token cost (so resize, compress, extract frames, transcribe), storage, retention and privacy obligations for uploaded media, content moderation for images and audio, prompt injection hidden in images or documents, and the need for evaluation datasets with real media.

Detailed explanation

Cost and latency. An image typically costs hundreds to a few thousand tokens depending on resolution and provider; audio and video are far more expensive, and large uploads add network time. Controls:

  • Resize and compress images to the resolution the task needs (a receipt needs legible text; a "what is this object" query needs much less). Providers often downscale internally anyway, so sending 12-megapixel photos wastes bandwidth.
  • Video: sample relevant frames or scenes instead of sending everything.
  • Audio: if the LLM only needs the words, transcribe first with a speech-to-text model and send text; use native audio models when tone or real-time speech matters.
  • Documents: use text extraction where reliable, page images where layout matters.

Storage, retention and privacy. Uploads may include faces, ID documents, medical images, screens with customer data or location metadata (strip EXIF/GPS). Define where media is stored, encryption, who can access it, how long it is retained, and whether it may be sent to third-party providers under your DPA. PII in images is harder to detect and redact than in text; OCR plus PII detection, or face blurring, may be needed.

Moderation. Text filters don't see images. Apply image and audio moderation (provider content safety, dedicated classifiers) on inputs and generated outputs, including detection of illegal content where legally required.

New injection vectors. Instructions can be hidden in images, screenshots, QR codes, low-contrast text or PDF layers ("ignore previous instructions and..."). Treat media from untrusted sources like untrusted text: limit what tools the model can trigger after reading it, and validate outputs.

Evaluation. Quality depends on image quality, lighting, handwriting, layout and language. Build eval sets with representative real media, including bad photos, rotated scans and edge cases.

How it works

  1. Validate file type and size; strip metadata.
  2. Moderate content; detect sensitive document types.
  3. Preprocess: resize, crop, frame-sample, transcribe.
  4. Send to model with least-privilege tools.
  5. Store per retention policy; log metadata, not raw media where possible.
  6. Evaluate on representative media sets.

Example

from PIL import Image, ImageOps

def prepare_image(path, max_side=1568):
    img = ImageOps.exif_transpose(Image.open(path))   # fix rotation
    img.thumbnail((max_side, max_side))               # cap resolution
    clean = Image.new(img.mode, img.size)
    clean.putdata(list(img.getdata()))                # drop EXIF/GPS metadata
    clean.save("upload.jpg", "JPEG", quality=85)
    return "upload.jpg"

Common mistakes

  • Sending full-resolution media by default.
  • Keeping uploaded photos forever "for debugging".
  • Moderating only text.
  • Ignoring instructions embedded in images.

How to answer in the interview

"Media inputs are large: an image can cost hundreds to thousands of tokens, audio and video far more, so I resize and compress images to what the task needs, sample video frames, and transcribe audio when the model only needs text. Uploaded media needs secure storage with clear retention and privacy rules, especially photos of people, IDs or medical images, and personal data in images is harder to redact. Moderation has to cover images and audio, not just text. Images and PDFs can hide prompt injections, so untrusted media is treated as untrusted input. And evaluation sets must include realistic media, because quality varies with image quality and layout."

Likely follow-up questions

  • User uploads a passport photo? Detect document type, minimise processing, mask numbers, short retention, check legal basis.
  • Real-time voice? Native speech models or streaming STT/TTS pipelines; latency budgets per stage.
  • Cost estimate for images? Use provider token formulas per resolution; test with samples.
