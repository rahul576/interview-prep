What are default and static methods in interfaces?

Java 8+ Features · concept · levels entry, mid

In one line

Since Java 8, a default method is an interface method with a body, inherited by implementations that may override it, and a static method is a utility belonging to the interface itself, called via InterfaceName.method(); defaults let interfaces evolve without breaking implementers, and conflicts are resolved by overriding with X.super.method().

Detailed explanation

Default methods are declared with the default keyword. Every implementing class inherits them automatically, and can override them for a better implementation. Their main purpose is interface evolution: the JDK added Collection.stream(), Iterable.forEach, Collection.removeIf, List.sort, Map.getOrDefault and Map.computeIfAbsent this way. They also enable fluent composition in functional interfaces, for example Predicate.and or Comparator.thenComparing. Default methods can call the interface's abstract methods, but they cannot access instance state, because interfaces have no instance fields, and they cannot override Object methods like equals.

Static interface methods belong to the interface, not to implementations or instances. They hold helpers and factories close to the type: Comparator.comparing, Comparator.naturalOrder, List.of, Map.entry, Stream.of, Function.identity. They are not inherited and can only be called via the interface name.

Diamond conflicts: if a class implements two interfaces that both provide a default method with the same signature, compilation fails until the class overrides it. Inside the override it can delegate to a specific one with InterfaceName.super.method(). Resolution rules: (1) class wins, so a method from a superclass beats any interface default; (2) the more specific interface wins (a sub-interface's default beats its parent's); (3) otherwise the class must override explicitly.

Java 9 added private interface methods (instance and static) to share code between default methods without exposing it.

How it works

  1. The compiler includes default method bodies in the interface class file.
  2. At runtime, method lookup finds the class's own override first, then the most specific default.
  3. Static interface methods are invoked with invokestatic on the interface.
  4. Ambiguous defaults produce a compile error in the implementing class.

Example

interface Notifier {
    void send(String msg);
    default void sendAll(List<String> msgs) { msgs.forEach(this::send); }   // default
    static Notifier console() { return System.out::println; }                // static factory
    private String prefix() { return "[notify] "; }                          // Java 9 private
}

interface Logger { default void log(String m) { System.out.println("L: " + m); } }
interface Auditor { default void log(String m) { System.out.println("A: " + m); } }

class AuditLogger implements Logger, Auditor {
    @Override public void log(String m) {          // must resolve the conflict
        Logger.super.log(m);
        Auditor.super.log(m);
    }
}

Notifier n = Notifier.console();
n.sendAll(List.of("order placed", "order shipped"));

Common mistakes

  • Treating default methods as a replacement for abstract classes (no state, no constructors).
  • Trying to call a static interface method through an implementing class or instance.
  • Not knowing the "class wins" rule.
  • Adding defaults that clash with existing method names in implementations.

How to answer in the interview

"Since Java 8 interfaces can have method bodies. A default method, declared with the default keyword, provides an implementation that implementing classes inherit but can override; List.sort and Collection.stream are examples. A static method belongs to the interface and is called through the interface name, used for helpers and factories like Comparator.comparing or List.of. Defaults let interfaces evolve without breaking existing implementations. If a class inherits the same default from two interfaces, it must override it, and it can call a specific one with InterfaceName.super.method(). Java 9 also added private interface methods."

Likely follow-up questions

  • How do you resolve the diamond problem with two default methods? Override in the class and delegate with A.super.m() or B.super.m().
  • Can a default method override equals? No, that's a compile error.
  • Interface with defaults versus abstract class? Abstract classes can have state and constructors; interfaces allow multiple inheritance of behaviour.
