What are convolutional neural networks, and what are they used for?

AI/ML & GenAI · concept · levels entry, mid

In one line

Convolutional neural networks (CNNs) slide small learned filters over images to detect local patterns, use weight sharing and pooling for efficiency, and learn edges, then textures, then objects; they power classification, detection and segmentation, with vision transformers now a strong alternative.

Detailed explanation

Images are grids where nearby pixels are related. A fully connected layer on a 224×224×3 image would need about 150,000 weights per neuron and would ignore that structure. A convolutional layer instead learns small kernels (for example 3×3×channels) that slide across the image, computing a dot product at every position and producing a feature map showing where the pattern appears. Because the same kernel is reused everywhere (weight sharing), the layer has few parameters and recognises a pattern regardless of its location (translation equivariance). Stride and padding control output size, and each layer typically learns dozens to hundreds of filters.

Pooling (max or average) or strided convolutions downsample feature maps, reducing computation and giving some robustness to small shifts. Stacking layers grows the receptive field, so the network builds a hierarchy: edges and colour blobs, then textures and simple shapes, then object parts and whole objects. A final global pooling and dense layer produces class scores.

Landmark architectures include ResNet (residual connections enabling very deep networks), EfficientNet (balanced scaling of depth, width and resolution), MobileNet for edge devices, and ConvNeXt (a modernised CNN). Applications: image classification, object detection (YOLO family, Faster R-CNN), segmentation (U-Net, common in medical imaging), manufacturing quality inspection, OCR and video analysis. Vision transformers (ViT) split an image into patches and apply self-attention; with large datasets or pretraining they match or beat CNNs, and hybrid designs combine convolutional inductive bias with attention. For small datasets, a pretrained CNN with transfer learning remains a very practical choice.

How it works

  1. Input image as a tensor (height × width × channels).
  2. Convolution layers apply learned filters, followed by activations like ReLU.
  3. Pooling or strided convolution downsamples.
  4. Repeat, increasing the number of channels as spatial size shrinks.
  5. Global pooling and a classifier head output class probabilities; train with cross-entropy and backpropagation.

Example

import torch.nn as nn

cnn = nn.Sequential(
    nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(64, 128, kernel_size=3, padding=1), nn.ReLU(),
    nn.AdaptiveAvgPool2d(1), nn.Flatten(),
    nn.Linear(128, 10)
)

Common mistakes

  • Training from scratch on a few hundred images instead of fine-tuning a pretrained model.
  • No data augmentation, leading to overfitting.
  • Different preprocessing (resize, normalisation) at inference than at training.
  • Assuming pooling makes the network fully rotation or scale invariant.

How to answer in the interview

"CNNs are built for grid data like images. A convolutional layer learns small filters that slide over the image and respond to local patterns; because the same filter is shared across positions, they need far fewer parameters and detect a pattern anywhere. Pooling shrinks the maps, and stacked layers learn edges, then shapes, then objects. They're used for classification, detection, segmentation, medical imaging and inspection, with ResNet or EfficientNet as common backbones. Vision transformers are a strong alternative at scale, but for small datasets I'd fine-tune a pretrained CNN."

Likely follow-up questions

  • Classifier with only 500 labelled images? Fine-tune a pretrained backbone with heavy augmentation, freezing early layers.
  • What is a receptive field? The region of the input that influences a given feature; it grows with depth.
  • Why residual connections? They let gradients flow through very deep networks, easing training.
