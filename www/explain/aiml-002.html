Explain supervised, unsupervised and reinforcement learning with examples.

AI/ML & GenAI · concept · levels entry, mid

In one line

Supervised learning learns from labelled examples (spam detection, price prediction); unsupervised learning finds structure without labels (clustering, anomaly detection); reinforcement learning learns a policy from rewards for actions (games, robotics, RLHF); self-supervised learning creates labels from the data itself and powers LLM pretraining.

Detailed explanation

Supervised learning trains on input-output pairs: emails labelled spam or not spam, houses with their sale prices, transactions marked as fraud. The model learns a mapping from inputs to outputs and predicts outputs for new inputs. It covers classification and regression and is the most common type in business. Its main cost is labelling, which can be slow or expensive.

Unsupervised learning has no labels. The model discovers structure: clustering customers into segments by behaviour (k-means, DBSCAN), dimensionality reduction for visualisation or compression (PCA, UMAP), and anomaly detection, finding points that do not fit normal patterns, such as unusual server metrics or transactions.

Reinforcement learning (RL) has an agent that takes actions in an environment and receives rewards or penalties. Over many trials it learns a policy that maximises cumulative reward, balancing exploration and exploitation. Examples are game playing (AlphaGo), robotics, recommendation and ad bidding, and RLHF or related methods used to align language models with human preferences.

Self-supervised learning sits between: labels come from the data itself, such as predicting the next token in text or masked words or image patches. This lets models learn from huge unlabelled datasets and is how LLMs are pretrained. Many real systems mix types; for example semi-supervised learning uses a few labels and many unlabelled examples.

How it works

  1. Supervised: collect labelled data, train, validate on held-out labels, predict.
  2. Unsupervised: choose a structure to find (clusters, components, outliers), fit on unlabelled data, interpret.
  3. Reinforcement: define environment, actions and reward; the agent iterates act, observe reward, update policy.
  4. Self-supervised: mask or shift data to create targets; pretrain; fine-tune for tasks.

Example

from sklearn.linear_model import LogisticRegression
from sklearn.cluster import KMeans
from sklearn.ensemble import IsolationForest

spam_model = LogisticRegression().fit(X_emails, y_is_spam)        # supervised
segments   = KMeans(n_clusters=5, n_init="auto").fit_predict(X_customers)   # unsupervised
outliers   = IsolationForest(contamination=0.01).fit_predict(X_transactions)  # unsupervised anomaly

Common mistakes

  • Calling clustering "classification".
  • Thinking RL just means "learning from feedback" of any kind.
  • Ignoring the cost and quality of labels in supervised projects.
  • Treating LLM pretraining as supervised with human labels.

How to answer in the interview

"In supervised learning the model learns from labelled examples, like emails marked spam or past house sales with prices, and predicts labels for new data. Unsupervised learning has no labels and finds structure, like customer clusters or anomalies. In reinforcement learning an agent takes actions, gets rewards and learns a policy that maximises them, as in game playing, robotics or RLHF for language models. There's also self-supervised learning, where labels come from the data itself, like predicting the next word, which is how LLMs are pretrained."

Likely follow-up questions

  • Fraud with few labels? Anomaly detection plus semi-supervised learning, adding labels as analysts confirm cases.
  • What is RLHF? Training a reward model from human preferences, then optimising the LLM against it.
  • Semi-supervised? A few labels plus lots of unlabelled data.
