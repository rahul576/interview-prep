How do you call a static interface method?

Java 8+ Features · concept · levels entry

In one line

Call a static interface method through the interface name, such as Comparator.naturalOrder() or List.of(1, 2); static interface methods are not inherited by implementing classes or instances and cannot be overridden.

Detailed explanation

Static methods in interfaces (Java 8+) are utilities attached to the type. The only valid call syntax is InterfaceName.method(args). Within the interface itself (e.g. from a default method) you can call it unqualified.

Unlike static methods of classes, which subclasses inherit (you can write SubClass.staticMethod() and even, with a warning, instance.staticMethod()), static interface methods are not inherited:

  • ArrayList.of(1, 2) doesn't compile, even though ArrayList implements List.
  • myList.of(1, 2) doesn't compile either.
  • An implementing class may declare its own static method with the same signature, but that's an unrelated method, not an override; there's no polymorphism for statics.

Why this design? A class can implement many interfaces. If statics were inherited, two interfaces with the same static method signature would create ambiguity in every implementing class, and adding a static method to an interface could break existing implementers. Keeping them non-inherited makes interfaces safe to evolve and keeps call sites explicit about where a method comes from.

Static interface methods are commonly used for factory methods (List.of, Set.of, Map.of, Stream.of, Path.of), combinator helpers (Comparator.comparing, Function.identity, Predicate.not), and default implementations of your own interfaces (Notifier.console()), replacing separate utility classes like the old Collections pattern. They are implicitly public unless declared private (Java 9).

How it works

  1. Declare static with a body inside the interface.
  2. The compiler resolves Interface.method() with invokestatic on the interface.
  3. Lookups through an implementing class or instance fail at compile time.
  4. A same-signature static in a class simply hides nothing; it is a separate method.

Example

public interface Shape {
    double area();

    static Shape circle(double r) { return () -> Math.PI * r * r; }   // factory
    static Shape square(double s) { return () -> s * s; }
    static double totalArea(List<Shape> shapes) {
        return shapes.stream().mapToDouble(Shape::area).sum();
    }
}

class Rect implements Shape {
    final double w, h;
    Rect(double w, double h) { this.w = w; this.h = h; }
    public double area() { return w * h; }
}

double total = Shape.totalArea(List.of(Shape.circle(1), Shape.square(2), new Rect(2, 3)));

// Rect.circle(1);              // compile error: not inherited
// new Rect(1, 2).square(2);    // compile error
List<String> names = List.of("a", "b");                 // JDK example
Comparator<String> cmp = Comparator.naturalOrder();

Common mistakes

  • Calling via an implementing class or an instance.
  • Expecting a class's same-name static to override the interface method.
  • Putting stateful logic in static interface methods.
  • Confusing static methods with default methods, which are inherited.

How to answer in the interview

"I call it with the interface name, like Comparator.naturalOrder(), List.of(1, 2) or MyValidator.isValid(x). Unlike static methods in classes, static interface methods aren't inherited, so I can't call them through an implementing class name or an instance, and an implementing class can't override them; it can only declare its own unrelated method with the same signature. That keeps them as utilities attached to the interface, typically factory methods that return implementations, and avoids ambiguity when a class implements several interfaces."

Likely follow-up questions

  • Why are static interface methods not inherited? To avoid ambiguity across multiple interfaces and keep interface evolution safe.
  • Can a static interface method be private? Yes, since Java 9.
  • Can a default method call a static method? Yes, unqualified within the interface.
